La carpeta features agrupa todo el código relacionado con una funcionalidad de la aplicación.

Cada carpeta representa un módulo independiente del negocio.

Ejemplos:

inspection
environment
observation
photo
report

La ventaja es que, si mañana debes modificar únicamente las inspecciones, casi todo el código estará dentro de features/inspection y no repartido por veinte carpetas distintas.
