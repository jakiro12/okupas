# Modelo de Datos (V1)

## Inspection

```text
Inspection
------------------------------
id                  -- UUID
title               -- TEXT
clientName          -- TEXT
propertyAddress     -- TEXT
city                -- TEXT
province            -- TEXT
notes               -- TEXT
status              -- TEXT
createdAt           -- DATETIME
updatedAt           -- DATETIME
```

---

## Environment

```text
Environment
------------------------------
id                  -- UUID

name                -- TEXT
orderIndex          -- INTEGER
createdAt           -- DATETIME
```

---

## Observation

```text
Observation

```

# Relaciones

```text
Inspection
│
├── Environment
│      └── inspectionId → Inspection.id
│
├── Report
│      └── inspectionId → Inspection.id
│
Environment
│
└── Observation
       └── environmentId → Environment.id

Observation
│
└── Photo
       └── observationId → Observation.id
```
